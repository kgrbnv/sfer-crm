# Исследование CRM-систем для B2B продаж с высоким чеком

**Дата:** 2026-01-14
**Контекст:** Анализ для агентского бизнеса с чеком 750K-1M руб (≈$10K-15K USD), команда 3-5 человек

---

## Executive Summary

### Ключевые выводы

1. **Для высокого чека критичны:**
   - Кастомизация полей и стадий воронки
   - Автоматизация повторяющихся задач
   - История взаимодействий (email, звонки, встречи)
   - Аналитика конверсии по стадиям
   - Интеграция с календарём и почтой

2. **Лидеры по категориям:**
   - **Enterprise:** Salesforce (но избыточен для команды <10)
   - **Баланс:** HubSpot, Pipedrive
   - **Россия:** AmoCRM, Bitrix24
   - **Гибкость:** Monday, Notion/AirTable

3. **Оптимальный выбор для стартапа 2026:**
   - **Быстрый старт:** HubSpot Free → Starter
   - **Кастомизация:** Notion + автоматизация
   - **Россия:** AmoCRM (Telegram/WhatsApp из коробки)

## 2. Salesforce

### Позиционирование
Enterprise-grade CRM, стандарт индустрии. Максимальная кастомизация, но требует настройки.

### Ключевые функции для B2B

| Функция | Описание | Критичность для high-ticket |
|---------|----------|---------------------------|
| **Opportunity Management** | Управление сделками с детализацией продуктов | ⭐⭐⭐⭐⭐ |
| **Account Hierarchy** | Структура клиента (холдинг → дочки) | ⭐⭐⭐⭐ (для enterprise) |
| **Einstein AI** | Scoring лидов, рекомендации, прогнозы | ⭐⭐⭐⭐ |
| **Customization** | Полная кастомизация объектов, полей, логики | ⭐⭐⭐⭐⭐ |
| **Role Hierarchy** | Сложные права доступа по ролям | ⭐⭐ (для команды <10 избыточно) |
| **CPQ** | Configure-Price-Quote для комплексных продаж | ⭐⭐⭐ (если кастомные решения) |

### Почему лидер для Enterprise

1. **Бесконечная кастомизация**: можно построить любую бизнес-логику
2. **AppExchange**: 5000+ готовых интеграций
3. **Масштабируемость**: от 10 до 10,000+ пользователей
4. **Экосистема**: огромное комьюнити, сертифицированные консультанты
5. **Соответствие**: compliance для банков, медицины, финтех

### Автоматизация

- **Process Builder**: визуальная автоматизация (if-then логика)
- **Flow Builder**: сложные многошаговые процессы
- **Approval Processes**: согласование сделок по иерархии
- **Einstein Bots**: чат-боты для квалификации лидов

### Интеграции

| Тип | Варианты |
|-----|----------|
| **Мессенджеры** | WhatsApp (через Twilio), Telegram (партнёрские решения) |
| **Email** | Outlook, Gmail (Einstein Activity Capture) |
| **Календарь** | Двусторонний sync, Salesforce Scheduler |
| **Звонки** | Sales Dialer, интеграции с любой телефонией |

### Аналитика

- **Reports**: 200+ типов отчётов
- **Dashboards**: real-time дашборды
- **Einstein Analytics**: AI-driven инсайты
- **Forecasting**: прогнозы с учётом вероятности и истории

### Стоимость (для 5 пользователей)

| Тариф | $/мес (×5) | Функционал |
|-------|-----------|------------|
| Essentials | $125 | Базовая CRM (до 10 пользователей) |
| Professional | $400 | Полная автоматизация, API |
| Enterprise | $800 | Кастомизация, multiple pipelines |
| Unlimited | $1,500 | Все функции + поддержка 24/7 |

**Рекомендация для high-ticket:** Professional ($400/мес) минимум.

### Плюсы/минусы для агентского бизнеса

✅ **Плюсы:**
- Можно построить абсолютно любую логику
- Огромная экосистема интеграций

❌ **Минусы:**

## 4. Bitrix24

### Позиционирование
Всё-в-одном: CRM + проекты + корпоративный портал. Популярен в России.

### Ключевые функции для B2B

| Функция | Описание | Критичность для high-ticket |
|---------|----------|---------------------------|
| **CRM** | Лиды, сделки, компании, контакты | ⭐⭐⭐⭐⭐ |
| **Проекты** | Канбан, Гант, задачи (интеграция с CRM) | ⭐⭐⭐⭐ (для агентств) |
| **Чаты** | Внутренний мессенджер, видеозвонки | ⭐⭐⭐ |
| **Диск** | Облачное хранилище документов | ⭐⭐⭐ |
| **Сайты** | Конструктор лендингов + CRM | ⭐⭐ |
| **Телефония** | Встроенная IP-телефония | ⭐⭐⭐ |

### Что отличает

1. **Всё в одном**: не нужны отдельно Slack, Asana, Google Drive
2. **Проекты + CRM**: можно связать сделку и проект выполнения
3. **Бесплатный тариф**: до 12 пользователей (но ограничения)
4. **Российский**: сервера в РФ, поддержка 24/7 на русском

### Автоматизация

- **Бизнес-процессы**: визуальный конструктор (как Process Builder в Salesforce)
- **Роботы**: триггеры на создание, изменение сделки
- **Триггеры email/SMS**: автоотправка по событиям
- **CRM-маркетинг**: рассылки, сегментация

### Интеграции

| Тип | Варианты |
|-----|----------|
| **Мессенджеры** | WhatsApp, Telegram, VK (как в AmoCRM) |

### Аналитика

- CRM-аналитика (воронки, конверсия)
- Отчёты по проектам (времятрекинг)
- Дашборды с метриками
- Экспорт в Excel/CSV

| Тариф | ₽/мес | Функционал |
|-------|-------|------------|
| Бесплатный | 0 | Базовая CRM, 5 ГБ, ограничения |
| Базовый | 2,490 | 24 ГБ, автоматизация |
| Стандартный | 4,990 | CRM-маркетинг, отчёты |
| Профессиональный | 9,990 | Бизнес-процессы, интеграции |
| Энтерпрайз | 19,990 | Всё + приоритетная поддержка |

**Рекомендация для high-ticket:** Стандартный (4,990₽/мес ≈ $55).

### Плюсы/минусы для агентского бизнеса

✅ **Плюсы:**
- **CRM + управление проектами** в одном месте
- Мессенджеры из коробки
- Дёшево (особенно бесплатный тариф)
- Российская локализация
- Интеграция с 1C

❌ **Минусы:**
- **Перегружен функциями**: сложно освоить (2-3 недели обучения)
- UI местами запутанный
- Медленный (особенно на облаке, on-premise быстрее)
- Автоматизация слабее AmoCRM (конструктор менее гибкий)
- Фокус размыт (всё понемногу, ничего идеально)

**Вывод для агентства:** Если нужен CRM + проекты — рассмотреть. Если только продажи — AmoCRM проще.

## 7. No-Code CRM на AirTable/Notion

### AirTable как CRM

**Концепция:** База данных + интерфейсы + автоматизация = кастомная CRM.

#### Базовая структура

**Таблицы:**
1. **Deals** (Сделки)
   - Name, Stage, Amount, Close Date
   - Link to Company, Contact
2. **Companies** (Компании)
   - Name, Industry, Website
   - Link to Deals, Contacts
3. **Contacts** (Контакты)
   - Name, Email, Phone, Role
   - Link to Company, Deals
4. **Activities** (Активности)
   - Type (Call, Meeting, Email), Date, Notes
   - Link to Deal

#### Автоматизация в AirTable

**Бесплатно (до 100 runs/мес):**
- При смене Stage → отправить email
- При создании Deal → создать задачу в Notion
- При Close Date < Today → уведомление в Slack

**Платно ($20/user/мес):**
- Неограниченные автоматизации
- Интеграция с Gmail (отправка из AirTable)
- Webhooks для внешних систем

#### Интеграции

| Способ | Возможности |
|--------|-------------|
| **Native** | Slack, Gmail, Google Calendar (ограниченно) |
| **Zapier/Make** | WhatsApp, Telegram, любые мессенджеры |
| **API** | Кастомная интеграция (нужен разработчик) |

#### Стоимость

| Тариф | $/мес (для 5) | Автоматизации | Хранилище |
|-------|---------------|---------------|-----------|
| Free | 0 | 100 runs/мес | 1,000 записей/база |
| Plus | 100 | 25,000 runs/мес | 5,000 записей/база |
| Pro | 250 | 100,000 runs/мес | 50,000 записей/база |

#### Плюсы/минусы

✅ **Плюсы:**
- Полная кастомизация структуры
- Красивые интерфейсы (формы, галереи, канбан)
- Дёшево (Free tier мощный)
- Можно построить уникальную логику

❌ **Минусы:**
- **Нужно строить с нуля**: нет готовой CRM
- Нет встроенного email tracking
- Нет IP-телефонии
- Автоматизации лимитированы (vs настоящих CRM)
- Scaling сложный (>10K сделок тормозит)

**Для кого:** Стартапы с очень специфичными процессами, где стандартные CRM не подходят.

### Notion как CRM

**Концепция:** Databases + Relations + Formulas = простая CRM.

#### Базовая структура

**Databases:**
1. **Deals Database**
   - Stage (select: Lead, Proposal, Negotiation, Closed Won/Lost)
   - Amount (number), Close Date (date)
   - Relation: Company, Contact
2. **Companies Database**
   - Name, Industry, Website
   - Relation: Deals
3. **Contacts Database**
   - Name, Email, Phone
   - Relation: Company, Deals
4. **Activities Database**
   - Type, Date, Notes
   - Relation: Deal

#### Автоматизация в Notion

**Встроенная (ограниченная):**
- Button actions (создать связанную страницу)
- Formulas (расчёт ARR, days since contact)
- Rollups (сумма сделок по компании)

**Через Zapier/Make:**
- При новой сделке → уведомление в Telegram
- При смене Stage → создать задачу в Todoist
- При Close Date → напоминание в календарь

#### Интеграции

| Способ | Возможности |
|--------|-------------|
| **Встроенные** | Нет (только embed) |
| **Zapier/Make** | Gmail, Календарь, Telegram, WhatsApp |
| **API** | Кастомная интеграция |

#### Стоимость

| Тариф | $/мес (для 5) | Функционал |
|-------|---------------|------------|
| Free | 0 | Неограниченные pages, базовые databases |
| Plus | 50 | Неограниченные file uploads, version history |
| Business | 75 | SAML SSO, advanced permissions |

#### Плюсы/минусы

✅ **Плюсы:**
- **Очень дёшево** (Free tier достаточен)
- Гибкость (можно добавить любые поля)
- Красивые интерфейсы (Board, Table, Calendar views)
- Можно хранить заметки по сделкам прямо там

❌ **Минусы:**
- **Нет автоматизации из коробки** (только через Zapier)
- Нет email tracking
- Нет IP-телефонии
- Медленный (vs настоящих CRM)
- Не CRM-специфичные фичи (нет воронки конверсии)

**Для кого:** Очень маленькие команды (1-3 человека) с простыми процессами.

## 8. No-Code CRM на Supabase

### Концепция

**Supabase** = open-source Firebase (PostgreSQL + Auth + API + Realtime).

**Идея:** Построить кастомную CRM используя:
- **Supabase Backend**: PostgreSQL база + RESTful API
- **Frontend**: Next.js / React / Vue
- **Автоматизация**: Supabase Functions (Deno) + webhooks

### Архитектура

```
PostgreSQL (Supabase)
├── deals (id, stage, amount, company_id)
├── companies (id, name, industry)
├── contacts (id, name, email, company_id)
└── activities (id, type, deal_id, date)

Supabase API (auto-generated)
├── REST API для CRUD
├── Realtime subscriptions
└── Row Level Security (RLS)

Frontend (Next.js)
├── Dashboard (deals pipeline)
├── Company/Contact views
└── Activity timeline

Automation (Supabase Edge Functions)
├── On deal stage change → send email
├── On new contact → enrich via API
└── Scheduled: reminder emails
```

### Готовые решения

**1. BaseRow (Open-source AirTable на Supabase):**
- Self-hosted или cloud
- GUI для построения баз данных
- API + webhooks
- Бесплатно (self-hosted)

**2. NocoDB (Open-source AirTable/Notion):**
- Работает поверх любой БД (включая Supabase)
- GUI интерфейсы (Grid, Kanban, Calendar)
- Автоматизации + webhooks
- Бесплатно (self-hosted)

**3. Directus (Headless CMS + Database):**
- Построить CRM на Supabase
- Admin panel из коробки
- Flows (автоматизация)
- Бесплатно (self-hosted)

### Пример: Простая CRM на Supabase + NocoDB

**Шаги:**
1. Создать Supabase проект (бесплатно)
2. Развернуть NocoDB (Docker или cloud)
3. Подключить NocoDB к Supabase PostgreSQL
4. Создать таблицы (Deals, Companies, Contacts)
5. Настроить Views (Kanban для воронки)
6. Webhook: при смене Stage → n8n → Telegram уведомление

**Стоимость:**
- **Supabase Free tier**: 500 MB DB, 1 GB file storage, 50,000 MAU
- **NocoDB Self-hosted**: бесплатно (нужен сервер $5-10/мес)
- **Итого**: ~$10/мес (vs $50-200/мес за SaaS CRM)

### Плюсы/минусы

✅ **Плюсы:**
- **Полный контроль**: свой код, своя база
- Дёшево ($0-10/мес vs $100-500)
- Можно построить ЛЮБУЮ логику
- Open-source, нет vendor lock-in
- Интеграция с чем угодно (Telegram, WhatsApp через API)

❌ **Минусы:**
- **Нужен разработчик** (или сильный no-code навык)
- Нет UI из коробки (нужно строить на NocoDB/BaseRow)
- Нет email tracking, IP-телефонии
- Поддержки нет (community only)
- Время на разработку (2-4 недели минимум)

**Для кого:**
- Технические стартапы с разработчиком в команде
- Очень специфичные процессы (стандартные CRM не подходят)
- Нужна интеграция с кастомными системами

## 9. Современные подходы к CRM для стартапов (2026)

### Тренд 1: Composable CRM (модульная CRM)

**Концепция:** Не покупать монолитную CRM, а собрать из best-of-breed инструментов.

**Пример стека:**
- **Deals**: AirTable/Notion
- **Email**: Gmail + Superhuman
- **Scheduler**: Calendly/Cal.com
- **Automation**: Zapier/Make
- **Analytics**: Google Sheets + Looker Studio
- **Communication**: Telegram + WhatsApp (native apps)

**Плюсы:**
- Лучшие инструменты в каждой категории
- Гибкость (легко заменить модуль)
- Часто дешевле монолита

**Минусы:**
- Нет single source of truth
- Интеграции могут ломаться
- Сложность управления

---

### Тренд 2: AI-First CRM

**Примеры:**
- **Clay**: AI-обогащение данных о лидах
- **Apollo.io**: AI-поиск prospects + outreach
- **Salesforge**: AI SDR (автоматизированные cold emails)

**Функции:**
- AI-скоринг лидов (кто вероятнее купит)
- Автоматическая квалификация
- Генерация персонализированных писем
- Предсказание churn

**Для high-ticket B2B:**
- Clay для исследования клиентов перед звонком
- AI-помощь в составлении proposal
- Автоматический анализ call recordings (Gong, Chorus)

---

### Тренд 3: Messenger-First CRM

**Для рынков где мессенджеры > email (Россия, LatAm, MENA):**

**Подход:**
- Вся коммуникация через WhatsApp/Telegram
- CRM = история переписок + автоматизация ответов
- Боты для квалификации

**Инструменты:**
- **AmoCRM** (лидер в России)
- **Wazzup** (WhatsApp/Telegram CRM)
- **Chat2Desk** (омниканальная платформа)

**Для агентского бизнеса:**
- Клиенты предпочитают Telegram → AmoCRM must-have
- Можно вести весь цикл сделки в мессенджере

---

### Тренд 4: Embedded CRM

**Концепция:** CRM внутри инструментов, где вы уже работаете.

**Примеры:**
- **Attio**: CRM-as-a-database (как Notion, но CRM-специфичная)
- **Folk**: CRM внутри email-клиента
- **Streak**: CRM внутри Gmail

**Для кого:** Команды, живущие в email (консультанты, freelancers).

---

### Тренд 5: No-Code CRM Builders

**Платформы:**
- **Softr** (на AirTable)
- **Stacker** (на Google Sheets/AirTable)
- **Internal.io** (на PostgreSQL/MySQL)

**Идея:** Взять базу данных (AirTable, Supabase) → построить UI через no-code.

**Для агентства:**
- Построить портал для клиентов (видят свои проекты)
- Кастомная воронка под свой процесс
- ~$50-100/мес (vs $200-500 за готовую CRM)

## 11. Минимальный функционал для high-ticket B2B

### Must-Have

| Функция | Зачем | Альтернатива |
|---------|-------|--------------|
| **Deal Pipeline** | Визуализация стадий сделки | Google Sheets (но неудобно) |
